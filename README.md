My core interest is **defensive security** — detecting threats, responding to incidents, and understanding attacker behavior well enough to build stronger defenses around it.

## 🧩 Featured Projects

### 🏥 [Hospital Web App Penetration Test (Black-Box)](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK4-PENETRATION-TESTING-REPORT)
Full black-box engagement against a web application target. Chained **username enumeration → SQL injection auth bypass** to reach restricted data without credentials, cracked password-protected PDFs via hash extraction, and used **Nikto** to surface an exposed database backup. Delivered a report with **6 CVSS 3.1-rated findings** and remediation.
`SQL Injection` · `Nikto` · `John the Ripper` · `Kali Linux`

### 📡 [Reconnaissance & Network Discovery Assessment](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK2-PENTESTING-TESTING-REPORT)
Footprinting and host-discovery assessment following **PTES** and **NIST SP 800-115**. Profiled a live target with WHOIS, dnsrecon, WhatWeb, header analysis, and WAF detection; mapped **11 live hosts on a /24** via a Zenmap/Nmap ARP sweep with OUI profiling. Flagged missing security headers, SPF/DMARC gaps, and segmentation risks.
`WHOIS` · `dnsrecon` · `WhatWeb` · `wafw00f` · `Zenmap`

### 🔑 [PDF Password Recovery & Hash Analysis](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK3-PASSWORD-CRACKING-REPORT)
Extracted PDF password hashes and recovered credentials through dictionary attacks using **John the Ripper** and the **Johnny GUI**, with a tooling comparison and defensive takeaways on password strength.
`Hash Cracking` · `John the Ripper` · `Password Security`

### 🧪 [Cybersecurity Lab Environment Setup](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK1-PM1-CYBERSECURITY-LAB-SETUP)
Built an isolated penetration-testing lab in **VirtualBox + Kali Linux** on a private NAT network — static IP, snapshots, and host-VM integration — and diagnosed/resolved a Linux NetworkManager connectivity issue.
`VirtualBox` · `Kali Linux` · `Linux Networking`

### 🎓 [HITEC University Projects](https://github.com/Ali-Abbas-Qazi/HITEC-Projects)
Academic project repository, including an **Insider Threat Detection Tool** (Python) that flags behavioral anomalies, plus coursework in C++, Java, and DSA.
`Python` · `C++` · `Java`
