## &nbsp;🧩&nbsp; Featured Projects

> Each project is a documented security engagement with methodology, evidence, and remediation.

### 🏥 &nbsp;[Hospital Web App Penetration Test — Black-Box](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK4-PENETRATION-TESTING-REPORT)
Full black-box engagement against a web application target. Chained **username enumeration → SQL injection authentication bypass** to reach restricted data without credentials, recovered password-protected PDFs via hash extraction, and used **Nikto** to surface an exposed, unauthenticated database backup. Delivered a report with **6 CVSS 3.1-rated findings** and remediation.

![SQLi](https://img.shields.io/badge/-SQL_Injection-c00000?style=flat-square) ![Nikto](https://img.shields.io/badge/-Nikto-262626?style=flat-square) ![JtR](https://img.shields.io/badge/-John_the_Ripper-111111?style=flat-square) ![Kali](https://img.shields.io/badge/-Kali_Linux-557C94?style=flat-square)

### 📡 &nbsp;[Reconnaissance & Network Discovery Assessment](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK2-PENTESTING-TESTING-REPORT)
Footprinting and host-discovery assessment following **PTES** and **NIST SP 800-115**. Profiled a live target with WHOIS, dnsrecon, WhatWeb, HTTP header analysis, and WAF detection; mapped **11 live hosts across a /24** via a Zenmap/Nmap ARP sweep with OUI vendor profiling. Flagged missing security headers, SPF/DMARC gaps, and segmentation risks across **6 severity-rated findings**.

![Recon](https://img.shields.io/badge/-Recon_/_OSINT-4682B4?style=flat-square) ![dnsrecon](https://img.shields.io/badge/-dnsrecon-134f5c?style=flat-square) ![Zenmap](https://img.shields.io/badge/-Zenmap-1D6FA5?style=flat-square) ![NIST](https://img.shields.io/badge/-NIST_SP_800--115-005288?style=flat-square)

### 🔑 &nbsp;[PDF Password Recovery & Hash Analysis](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK3-PASSWORD-CRACKING-REPORT)
Extracted PDF password hashes and recovered credentials through dictionary attacks with **John the Ripper** and the **Johnny GUI**, documenting the full workflow with a tooling comparison and defensive takeaways on password strength.

![Hashes](https://img.shields.io/badge/-Hash_Cracking-111111?style=flat-square) ![JtR](https://img.shields.io/badge/-John_the_Ripper-262626?style=flat-square) ![Passwords](https://img.shields.io/badge/-Password_Security-c00000?style=flat-square)

### 🧪 &nbsp;[Cybersecurity Lab Environment Setup](https://github.com/Ali-Abbas-Qazi/NETWORKWALKS-Ali-Abbas-Qazi-B083-WK1-PM1-CYBERSECURITY-LAB-SETUP)
Built an isolated penetration-testing lab in **VirtualBox + Kali Linux** on a private NAT network — static IP, VM snapshots, and host-VM integration — and diagnosed and resolved a Linux NetworkManager connectivity issue.
